# Сира — Викторина

Первая версия Android-приложения о жизнеописании Пророка Мухаммада ﷺ.

## Что уже есть
- главный экран с арабской каллиграфией «السيرة النبوية»;
- сложная викторина из 100 вопросов;
- 4 варианта ответа;
- таймер 30 секунд;
- подсчёт очков;
- объяснение после ответа;
- экран итогового результата;
- исламская цветовая палитра.

## Открытие проекта
Откройте папку проекта в Android Studio. Android Studio предложит синхронизировать Gradle.

## Следующий этап
Добавить 100+ проверенных вопросов, категории, рекорды, настройки, звуки, иконку приложения, рекламную/безрекламную модель при необходимости и подготовить AAB для Google Play.

Важно: религиозные материалы перед публикацией стоит проверить по надёжным источникам и, при возможности, с квалифицированным знающим человеком.


## Категории
Добавлены 8 тематических разделов по периодам жизни Пророка ﷺ и режим «Все категории» на 100 вопросов.


## Визуальная версия 1.1
Добавлен новый исламский фон главного экрана и иконка приложения в стиле макета «السيرة النبوية».
