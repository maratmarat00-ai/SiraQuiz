# Чек-лист Google Play

1. Создать приложение в Play Console.
2. Название: «Сира — Викторина».
3. Package name: com.siraquiz.app.
4. Тип: приложение.
5. Бесплатное приложение.
6. Загрузить подписанный Android App Bundle (.aab).
7. Заполнить карточку приложения и возраст/контент.
8. Добавить URL политики конфиденциальности.
9. Заполнить Data safety.
10. Проверить целевой API: Android 16 / API 36.
11. Пройти обязательное тестирование, если оно применяется к типу аккаунта разработчика.
12. Отправить релиз на проверку.

Примечание: package name является постоянным идентификатором, поэтому перед созданием приложения в Play Console его следует проверить ещё раз.
